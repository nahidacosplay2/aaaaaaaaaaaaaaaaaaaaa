# Zapret Aris — состояние проекта и план проверки

Дата ревизии: 2026-11-19.

## Состояние сейчас

В репозитории находятся два разных результата:

1. **Браузерный прототип** (`index.html`, `styles.css`, `app.js`) — только демонстрация экранов. Он хранит выбор в `localStorage`, не запускает VPN/TUN, ByeDPI, Xray, SOCKS5 или WebSocket-маршрут.
2. **Исходный Android-проект** (`android-app/`) — Java/XML-приложение с package ID `app.zapret.aris`, исходниками ByeDPI и HEV и отдельным прокси Telegram. В приложении предусмотрены маршруты локального Zapret и upstream SOCKS5.

**Готового публичного APK нет.** Android-сборка после миграции package ID и реализации SOCKS5-маршрута не выполнена, реальное устройство и end-to-end-трафик не проверены. Архивные APK/ZIP из репозитория удалены: это были референсные файлы другого приложения, не сборка Zapret Aris. Не использовать их контрольные суммы или метаданные как данные о релизе Aris.

### Текущая функциональная граница

- **Zapret:** локальный VpnService направляет IPv4 и доступный IPv6 через HEV к локальному ByeDPI.
- **SOCKS5:** HEV настроен на upstream SOCKS5 endpoint с необязательной аутентификацией и mapped DNS; можно исключить приложение, в котором работает локальный SOCKS-сервер. Проба проверяет только TCP handshake и тестовый TCP CONNECT.
- **Telegram:** отдельная служба, не является VPN-маршрутом для всех приложений.
- **VLESS/VMess/Trojan:** ядро Xray в приложение не добавлено. Поддерживается только SOCKS5 endpoint, в том числе SOCKS inbound уже работающего Xray.
- **Ограничение проверки:** поддержка UDP ASSOCIATE, DNS/AAAA, IPv6, Android TUN и реального переноса трафика через внешний сервер не подтверждена устройством.

### Известные результаты тестирования

Ранее `android-app/tests/vpn-sandbox-test.sh` вывел смешанные результаты для стратегий, но аудит показал, что в среде не было `nft`; скрипт молча продолжил работу без необходимого TTL-фильтра. Прошедшие/ошибочные результаты этого запуска не считаются достоверной оценкой стратегий. Скрипт исправлен: теперь он завершится с кодом 77, если обязательного `nft` нет. Повторный запуск в текущем окружении пропущен из-за отсутствия `nft`. Android SDK/JDK также отсутствуют, поэтому Gradle-сборка здесь блокируется отсутствием `java`.

В этой ревизии локальные Markdown-ссылки проверены; Python разобрал все 43 Android XML-ресурса/манифеста, `bash -n` прошёл для shell-скриптов, `py_compile` — для Python-файлов, `node --check` — для веб-интерфейса, JSON-ресурсы разобраны, а ByeDPI собран и запущен с `--help` на хосте. Это не проверяет Java-компиляцию, Android resource processing, APK-сборку, Android lint или runtime; JDK/SDK и `nft` в этой среде отсутствуют.

## Следующие этапы

### P0 — получить воспроизводимый Android APK

- Собрать release variant на чистом CI с JDK 17, Android SDK 35 и NDK `28.2.13676358`.
- Проверить сборку native-модулей для поддерживаемых ABI, APK signing, minification/ProGuard и размер страниц 16 KB.
- Сохранить логи и контрольную сумму конкретного артефакта; не включать APK в Git-исходники.

### P1 — проверить приложение на устройствах

- Установить APK на поддерживаемый Android и проверить запуск, VPN-разрешение, остановку, restart после изменения режима и сохранение настроек.
- Отдельно проверить Zapret-маршрут и SOCKS5-маршрут на Wi-Fi и мобильной сети.
- Проверить DNS A/AAAA, IPv4/IPv6, TCP и UDP/443; подтвердить отсутствие обхода туннеля для приложений, кроме явно исключённых.
- Проверить SOCKS5 с сервером без аутентификации, с аутентификацией, с отказом, timeout и недоступным UDP ASSOCIATE.
- Убедиться, что выбранное приложение с локальным SOCKS-сервером действительно исключается, а удалённый endpoint не уходит обратно в TUN.

### P2 — закрыть известные ошибки и оформить выпуск

- Разобрать провалы `vpn combo`, `vpn fake`, `general`; не менять стратегии без сохраняемых диагностических результатов.
- Подтвердить лицензии, происхождение исходной базы и версии встроенных зависимостей.
- Перед распространением подписать APK стабильным release-ключом, проверить установку/обновление, опубликовать commit, версию и SHA-256.
- Не обещать универсальный обход: результаты зависят от провайдера, сети, страны и конфигурации устройства.
